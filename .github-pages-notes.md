# GitHub Pages Deployment Notes

## Static Export Configuration

This site is configured for GitHub Pages deployment using Next.js static export.

- `output: 'export'` enabled in next.config.ts
- Base path set to `/agent-builder-framework/` for production
- All pages are pre-rendered as static HTML

## API Routes (Disabled for Static Export)

API routes have been moved to `/tmp/api-backend-disabled` as they cannot run in GitHub Pages static hosting.
The frontend pages (playground, docs, dashboard) are fully functional for display and documentation purposes.

For full functionality including live agent execution, deploy to:
- Vercel
- Railway  
- Any Node.js hosting platform
