HOW TO USE:
===========

STEP 1: Start Ollama (if not running)
  $ ollama serve

STEP 2: Pull a model (first time only)
  $ ollama pull mistral

STEP 3: Launch Stick Agent
  $ cd ~/development/stickai-agent-framework
  $ stick

STEP 4: Describe what you want to build!
  The AI will guide you through everything.

EXAMPLES:
=========

# Launch AI assistant (auto-connects)
stick

# Create an agent
stick init my-bot

# Run with Ollama
stick run my-bot --provider ollama --model mistral --interactive

# Create a workflow
stick workflow create my-pipeline

# Create MCP server
stick mcp create my-tools

# Create multi-agent system
stick multi-agent create my-system

# Deploy as API
stick deploy --port 3000

# Natural language (no AI needed for parsing)
stick "create a chatbot"
stick "deploy my agent"
