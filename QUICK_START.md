# 🚀 Stick.AI Framework - Quick Start

**Build AI agents by talking - Zero learning curve!** 🗣️🤖

---

## ⚡ 30-Second Start

```bash
# 1. Install Ollama (for AI assistant)
brew install ollama
ollama serve
ollama pull mistral

# 2. Start building!
cd ~/development/stickai-agent-framework
stick ai
```

**That's it!** Just tell the AI what you want to build! 💬

---

## 🎯 Three Ways to Build

### 1. AI Assistant (Easiest - Zero Code!)

```bash
stick ai
> "I want to build a chatbot that can search the web"
```

**AI does everything:**
- Understands your goal
- Asks clarifying questions  
- Generates commands
- Executes automatically
- Handles errors

### 2. Visual Playground (No Code!)

```bash
npm run dev
# Visit: http://localhost:3002/playground
```

**Drag & drop interface:**
- Visual agent builder
- Live preview
- Tool selection
- One-click deploy

### 3. Traditional CLI (Fastest!)

```bash
stick init my-agent
stick run my-agent --interactive
```

**Direct commands** for power users

## 📋 All Commands

```bash
# AI & Natural Language
stick ai                        Start AI assistant
stick <plain English>           Talk naturally

# Agents
stick init <name>               Create agent
stick run <name>                Run agent
stick deploy                    Deploy agent
stick list                      List agents

# MCP Servers
stick mcp create                Build custom server
stick mcp install <pkg>         Install server
stick mcp list                  List servers

# Multi-Agent
stick multi-agent create        Build system
stick multi-agent list          List systems
stick multi-agent run           Run system

# Monitoring
stick metrics                   View metrics
stick logs                      View logs

# Help
stick examples                  Show examples
```
